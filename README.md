# carmenairy

Tea tales of Carmenairy, since 2006. Live: https://keeonho.github.io/carmenairy/

Fairy-themed intro site for dorm @carmenairy (muse: Carmen of Hearts2Hearts): a lily blooms and the curtain opens, fairy dust follows your finger, petals fall, a spiral-notebook moodboard, the 26 fairy titles, and a teapot that pours as you scroll.

One `index.html` with GSAP ScrollTrigger and Lenis from CDN.
